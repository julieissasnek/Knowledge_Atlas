Pipeline Architecture

gap_extractor.py → query_results.json → harvest_layer.py (SerpAPI · scholarly · paper-scraper — scidownl reserved for Stage 3) → article_references.db → triage_engine.py (Stage 1: metadata · Stage 2: abstract+classify · Stage 3: PDF gate) → prisma_export.py (live PRISMA counts from DB → this page) → af_handoff.json (Article Finder boundary)

Decision Logic

Stage 1 (metadata-only — no network calls)
    title < 5 chars?           → stage1_status = fail  → final_decision = REJECT
    year outside [1990-2030]?  → stage1_status = fail  → final_decision = REJECT
    ALL-CAPS title?            → stage1_status = fail  → final_decision = REJECT

Stage 2 (abstract enrichment + heuristic classifier)
    DOI already seen in session?          → DUPLICATE
    abstract < 20 words after fallback?   → MISSING_ABSTRACT
    strong domain signals ≥ 2?          → ACCEPT
    strong ≥ 1  OR  weak ≥ 3?        → EDGE_CASE
    otherwise                             → REJECT

Stage 3 (PDF acquisition — ACCEPT + EDGE_CASE only)
    scidownl (Sci-Hub) is ONLY invoked here, never in the harvest stage.
    Acquisition order:
      1. Unpaywall open-access PDF URL
      2. Direct URL download (if URL ends in .pdf)
      3. scidownl last resort
